# Publication teaser images

Each paper shows its **Figure 1 / teaser** (downloaded from the paper's arXiv HTML
version). To replace one, drop a new file here with the exact name below — the page
references these paths, and a gold/silver placeholder with the paper acronym shows if
a file is missing.

| File | Paper |
|------|-------|
| `sigma.png`        | SIGMA (CVPR 2026) |
| `skeletonmamba.png`| Skeleton Mamba (ICCV 2025) |
| `graspmas.png`     | GraspMAS (IROS 2025) — paper Figure 2 (Planner/Coder/Observer pipeline) |
| `tcm.png`          | Temporally Conditional Mamba (SIGGRAPH Asia 2025) |
| `robodesign1m.png` | RoboDesign1M (preprint) |

The thumbnails are displayed small (cover-cropped to ~150×100) and load lazily, so
exact dimensions don't matter. `.jpg` works too — just update the `src` extension in
`index.html`.
